# Prodigy Infotech Internship - Task 01

## Stopwatch Web Application

A responsive and modern stopwatch web application built using HTML, CSS, and JavaScript.

## Features

- Start Timer
- Pause Timer
- Reset Timer
- Lap Recording
- Fastest Lap
- Slowest Lap
- Dark / Light Mode
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
